测试齿形参数

替代武器 DXF

仅临时替换武器齿形；叉子仍按自身开关选择测试叉面或当前 DXF。接触模型与材料参数不随此开关改变。

测试齿形：等待按齿数、打击圆、迎击面与背撑参数生成有限实体。

各齿按 360° / 齿数等角均布。“齿相位角”严格定义为齿尖半径与直线迎击面之间的有符号前角；牙长 L 就是迎击面从齿根到齿尖的长度，背撑厚度 t 把它闭合成三角实体。正值表示沿武器实际逆时针旋转方向前倾、齿尖相对齿根更“抓入”；输入值始终是最终装配后的物理前角，X/Y 镜像只改变安装朝向，不会暗中反转输入语义。它不控制第 0 齿圆周位置，第 0 齿位置由“武器初始角度”控制。0–15° 正前角是常用工程起点；超过 20° 不会被界面武断拒绝，但需另行校核齿根强度。Z 向齿宽仍在高级区“武器宽度 Z”设置。材料删除继续受连续接触安全门约束。

测试叉面参数

替代叉子 DXF

仅临时替换叉子作用面；武器仍按自身开关选择测试齿形或当前 DXF。接触模型与材料参数不随此开关改变。

测试叉面：等待按左端铰点与叉尖距离生成一条理想无厚度线段。

测试叉面严格是一条无厚度刚体线段：局部原点 O=(0,0) 是左端铰点，T=(D,0) 是右端叉尖，不暗造圆角、侧视厚度或三角背板。装配时只绕固定铰点转动，使叉尖在第一帧就位于真实 Y=0 mm 地面；不会先下落，也不会移动或改写铰点—武器原点距离。叉子质量仍使用高级区的显式输入，线段惯量按均匀细杆计算。关闭后恢复叉子 DXF。

MVP MODEL

读数如何使用

几何 / 理想值
由 KV、电压、传动比、轮径和转动惯量计算无负载上限。每齿 bite（mm/齿）= 接触点相对 X 向进给速度 ÷ 每秒实际齿通过次数；它不是材料切深。
CAD 与测试几何
叉子和武器各自独立选择当前 DXF 或“测试叉面 / 测试齿形”，因此共有四种组合。测试开关不删除已导入图纸，关闭即恢复；测试齿用“齿尖半径 + 直线迎击面 + 三角背撑”定义有限实体，测试叉严格是一条理想无厚度线段。叉子质量显式输入，测试线叉的质心与惯量按均匀细杆计算。
靶子轴向
靶子长度沿 X，厚度沿 Y。等效支撑间隙只定义靶子的持续支撑包络；叉子接触的真实地面仍固定为 Y = 0 mm。
整体运动
凹形 DXF 使用真实闭合边界，不用凸包填平牙谷；铰接叉子、转轴武器、靶子与无限地面由 Rapier 2D 自适应子步联立求解。叉子 X/Y 只定位铰点，叉身在重力与接触下自由转动；当前没有隐藏铰链限位或阻尼。底盘只有水平自由度，竖向与俯仰由理想地面约束，不能据此判断整机起跳或载荷转移。
局部材料接触
导入 CAD 与测试齿当前均采用非穿透零删料边界；h_min / Gc 可以记录，但连续“最早压缩接触 → 材料删除 → 余步重演”尚未通过收敛验证，因此安全门不会输出切削量或切屑体积。测试齿的直线迎击面、牙长和背撑会参与真实刚体几何接触，但不被冒充为已验证的材料去除模型。
收敛与回放
未来若启用连续材料删除，必须在同一固定时间步用相邻两档子步重复求解，删料、材料功、接触身份和终态任一不收敛都要回滚并停止；当前正式路径不会尝试删料。播放前先生成固定步长轨迹，播放、单步和进度条只读取已完成帧。

武器与行驶均按所选“真实加速 / 设定初速”模式起步。“高级参数（仅显示）”只展开或收起输入，不重置时间，也不切换求解律：已填的效率、有效输出系数、折扣、抓地、相电流限值、摩擦修正、恢复系数和刚体上限能量系数始终参与同一物理模型。0 A 表示没有可核验的相电流上限，不施加人为电流限矩；厂家桨测的电池侧电流不会被当作相电流。

武器碰撞使用已解析 DXF 的最大闭合外轮廓；孔、内圆与未闭合构造线不参与实体碰撞。若未来材料去除通过连续接触与收敛验证并被启用，只能归因于图纸识别出的真实迎击牙瓣；当前零删料路径不会删除材料。预测距离只作接近查询，正间隙不施力、不计命中或 bite。

局部材料模型是二维工程估算，不追踪裂纹扩展、刀刃磨损、温升、三维弯曲或应变率完整本构；材料功也不能直接解读为最终裂纹长度、真实损伤或赛场安全结论。刚体上限尤其不应作为真实击飞预测。
