# 武器咬入模拟器：开发交接

## 当前版本

- 当前开发版：`1.0.1`。
- 已冻结的 `v1.0` 发布副本位于项目同级的 `bite-simulator-v1.0` 文件夹；不要在该目录直接继续开发。
- 本目录可直接打开 `index.html` 使用，运行资源均为本地文件，不依赖联网加载。

## 本轮已完成

- 参数叉保持零厚度理想线段，并从第一帧让叉尖位于真实地面；叉子绕局部原点自由转动。
- CAD 武器与 CAD 叉使用三角复合实体，外轮廓继续接受独立的 `80 µm` 穿透审计。
- 参数齿的前角按最终装配后的物理正负定义，镜像不会把用户输入的正负含义反转。
- 参数武器、叉子、靶子与地面的持续多接触采用联立互补求解；已覆盖此前会停在靶子中的代表工况。
- “材料模型停止”“刚体求解停止”“内部异常停止”分开报告；任何失败步都会回滚到上一安全帧。
- 武器只填写总质量；转动惯量按当前 CAD/参数几何自动计算并只读显示。CAD 孔洞按奇偶规则扣除，参数齿先做多边形并集，避免重叠重复计质量。
- 数字栏可暂时清空再输入；清空草稿不会立即变红或触发重算。
- 仿真时长可在 `0.0005–4 s` 内选择，时间轴按 `0.5 ms` 固定步长工作；结果区显示靶子质心实时 X/Y 坐标。
- SIMD 可用时自动启用，初始化失败则回退普通 Rapier。

## 尚未完成的物理能力

- 真正的连续剐蹭、塑性沟槽、断裂与删料尚未通过连续 TOI、历史材料表面和时间步收敛验证。“有限材料”首次承载接触会安全回滚并停止；“理想刚体上限”只能作为不可变形上界。
- 导入 CAD 武器仍由 Rapier 三角复合实体处理持续接触，尚未接入参数齿使用的外轮廓持久 MLCP 接触见证。
- 底盘只有水平自由度，不能预测整机俯仰、起跳、轮组垂向或落地姿态。
- 自动惯量假设完整旋转组件质量沿可见二维几何均匀分布；轮毂、轴、皮带轮和紧固件分布不同会产生偏差。
- 极复杂接触可能需要大量回滚与子步，虽不会假装成功，但预计算仍可能较慢。

更完整的适用范围与限制见 [README.md](README.md)。

## 关键回归

在项目根目录执行：

```powershell
node work/run-final-static-qa.js
node work/run-ui-final-qa.js
node work/run-automatic-weapon-inertia-qa.js
node work/run-param-runtime-qa.js
node work/run-p0-failure-domain-qa.js
```

卡靶物理代表工况使用 `work/run-final-independent-physics-audit.js`；长矩阵耗时较高，源码或接触公式有变化时再运行。

## 后续优先级

1. 为 CAD 武器建立严格外轮廓接触见证，并接入现有持久多接触求解，保持内部 Earcut 边不参与事件归因。
2. 将材料本构、永久沟槽/损伤历史、最早压缩 TOI 与余步重演纳入同一事务求解，再开放连续剐蹭。
3. 将轨迹预计算移入 Worker；在结果逐值一致的前提下继续优化复杂接触性能。
4. 若要定量判断整机击飞，扩展为底盘平移/升降/俯仰与轮地接触模型。
