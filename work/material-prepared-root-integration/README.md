# S4a prepared least-root integration

This work-only module adds a capability-style prepared material root above the
frozen 9BD free-cluster contract and the frozen 8B Coulomb KKT solver. The new
v3 wrapper derives KKT work from 8B but refuses to claim a least root unless a
pinned geometry module provides conservative interval area bounds. It does not
wire the simulator main loop and does not publish material geometry.

## Contract

`createPreparedFreeClusterSession(adapter, config)` owns the sequence:

1. `advanceFree({h,event})` performs the one masked free advance and freezes
   `Sfree`, `qFree`, `Wact`, `Minv` and every contact row.
2. `prepareLeastRoot(token)` calls the certified v3
   `prepareMaterialEvent` on only that frozen frame. A per-`p` cache prevents
   the raw `freshArea` callback from being entered twice. The callback must
   have a registered `callbackDomain` with `snapshot()` and `restore()`;
   mutation of that domain is restored and refused. The callback's separate
   `boundFreshAreaInterval(lo,hi)` implementation is trusted only when both
   its module hash and the loaded v3 solver hash match session-config pins.
   Each root-excluded interval carries a conservative F range and the ordered
   leaves cover the complete prefix before the accepted bracket. If a bound is
   absent or cannot exclude zero, v3 refines left-first or safely stops the
   material domain; point samples alone are never accepted as proof.
   A negative residual at the stopping impulse is diagnostic only: because the
   geometry oracle may be non-monotone, it cannot bypass the interval tree or
   prove that an interior tangential root is unaffordable.
   A successful prepared root is also an identity capability owned by the
   exact loaded v3 module instance. Certificate hashes remain useful integrity
   telemetry, but a cloned, deserialized, cross-instance, or self-resigned JSON
   object is never accepted as an authoritative prepared event.
3. `verifyPreparedRoot(token, root)` accepts only the same frozen object
   generated by that session/token. A clone, later root, mixed payload or stale
   token is not a capability and is refused.
4. `finishMaterial(token, {preparedRoot})` performs zero solver calls and zero
   `freshArea` calls. It writes the already-bound `qPost` once and returns a
   commit ticket containing the same `p`, KKT modes/impulses, work, fresh area
   and geometry payload.

Both preparation and finish take adapter plus callback-domain root snapshots.
Any exception restores physical state, solver groups, callback-visible state,
audit counters and token retry state. Geometry remains staged in the returned
ticket for the later S4 transaction.

The old `createFreeClusterSession` and `solveClusterFromFree` exports are
delegated byte-for-byte to frozen 9BD so its P0 conformance remains unchanged.
