# Material free-cluster QA

This directory is an independent activation gate for the next material/contact integration stage. It does not edit or enable the production candidate.

## Contents

- `CONTRACT.md` defines the free-state, token, contact-frame, finish-branch, `h`, restitution, recovery, and finite-domain rules.
- `fixture.js` provides a deterministic serialisable world/solver-group adapter and signed-Coulomb preparation helpers.
- `pure-reference.js` is a small executable state machine implementing the proposed integration API. It also exposes ten deliberate contract mutants used only to prove that the QA detects regressions.
- `contract-core.js` contains the reusable black-box assertions.
- `run-tests.js` runs the reference, negative mutation tests, and optionally the frozen integration module.
- `test-report.json` is a deterministic report generated by the runner.

## Run now

```powershell
node work/material-free-cluster-qa/run-tests.js
```

The expected pre-integration result is:

- reference contract tests all pass;
- all deliberate mutants are caught; and
- integration status is `awaiting-module`.

## Run the frozen integration

```powershell
node work/material-free-cluster-qa/run-tests.js --module work/material-free-cluster-integration/free-cluster.js
```

This loads that module directly and applies the identical black-box suite. A missing export, source-lock drift, missing fault edge, state mutation, mode truncation, or binding mismatch makes the process exit nonzero.

## Deliberate negative mutations

The harness proves sensitivity to these errors:

- two world steps;
- mutable/recomputed actuation work;
- both finish branches consuming one `Sfree`;
- dry-trial state mutation;
- mixed accepted parameter/state;
- split interval `h`;
- leaked solver groups;
- restitution replay on a persistent contact; and
- truncating Coulomb candidates instead of a domain stop.

The pure reference is a QA oracle, not a production physics replacement. Actual Rapier contact extraction, production timing, geometry commit, chip/body staging, and main-switch activation remain outside this directory.
