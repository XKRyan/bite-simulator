# BITE LAB｜格斗机器人武器 bite 可视化模拟器

浏览器端中文 2D MVP。直接打开 `index.html` 即可运行；不需要安装依赖。

## 当前默认模型

- 武器：`新单牙大武器-P 8mm厚 3个.DXF`
- 叉子：`厚叉子.DXF`

两份图纸已内置到页面，默认加载的是真实 DXF 轮廓。`assets/` 也保留了原始 DXF 副本，`assets/default-models.js` 使网页在直接双击打开（`file://`）时仍能加载默认模型。

DWG 没有被伪装成已支持：浏览器端请先将 DWG 导出为 ASCII DXF；页面保留了后续接入 ODA / 服务端转换的说明入口。

### DXF 导入边界

- 当前可无损进入仿真的实体为 `LINE`、`ARC`、`CIRCLE`，以及不含 bulge 的 `LWPOLYLINE` / `POLYLINE`。
- 只接受世界 XY 平面、默认 `+Z` 法向、零 elevation / thickness / width 的轮廓。非零 Z、倾斜或反向 extrusion、非数值组码都会带稳定错误码被拒绝。
- 拓扑必须能无损形成一个外环及其普通孔。开放轮廓、模糊端点连接、自交、多个独立外环、相交/嵌套孔都会被拒绝；端点等价使用 `0.0001 mm` 欧氏距离数值阈值，不会再把 `0.2 mm` 缺口补成实体。
- 孔会作为真实空腔进入渲染、Earcut 碰撞三角化、叉子面积/质心/惯量、初始重叠和运行时穿透审计，不会被填实。
- 为避免牙形被悄悄拉直或丢失，含非零 group 42 bulge、3D/网格 polyline、`SPLINE`、`ELLIPSE`、`INSERT` / `MINSERT`、`MLINE`、`HATCH`、`SOLID`、`3DFACE`、`TRACE`、`REGION`、`BODY` 或代理实体的文件会被明确拒绝，不会带着被改变的轮廓继续求解。
- 建议在 CAD 中先炸开块引用，并把复杂曲线按可控弦高误差转换为 `LINE` / `ARC` / 无 bulge polyline；未被引用的 `BLOCK` 定义可以保留。

## 坐标约定

- 页面中的场景坐标、半径、轮径、长度、厚度、间隙、bite 与几何侵入均以 `mm` 输入或显示；线速度仍以 `m/s` 显示。
- 场景坐标系：画布网格的 `(0, 0) mm`，独立存在。
- 武器局部原点：当前武器转轴 / CAD 轴心。武器可以用“武器场景 X/Y”放到任何场景位置。
- 叉子坐标：输入的是叉子 CAD / 测试叉面原点相对武器局部原点的 X/Y。该原点同时是叉子铰点；X/Y 只确定铰点位置，不固定叉身转角，也不直接参考场景原点。
- 真实地面：固定在场景 `Y = 0 mm`，不可调；独立叉子刚体直接与该平面接触并在重力下自然落下。
- 靶子：长度沿 X、厚度沿 Y；“靶子场地 X + 离地间隙”定义它的持续支撑包络，默认支撑平面在 `Y = 0.1 mm`。这不是把真实地面整体抬高，叉子仍接触 `Y = 0 mm`。

默认几何会使用内置图纸推导武器轴高 = 图纸有效半径 × `1.05`。叉子不会再通过改写 Y 坐标或固定世界角度强制贴地；铰点沿用它相对武器原点的 X/Y，叉身姿态由重力、铰链约束和真实地面接触共同求解。闭合武器 DXF 的刀尖半径、齿数和碰撞几何均以图纸为准，手工“设计齿数”仅作为未闭合图纸的读数后备。

内置 1.36 kg 示例的武器初始角为 `75°`、靶子 X 为 `380 mm`。该相位位于经逐度复测的牙齿优先接触区间内，使默认“理想刚体上限对照”的第一次承载武器接触归类为真实牙齿，而不是背板；它没有改变材料安全门或 0.08 mm 穿透硬门。

叉子和武器可以分别绕自身局部原点镜像，开关就在各自 DXF 导入卡旁边。

两张导入卡还各有一个互不依赖的调试开关：武器可临时切换为“测试齿形”，叉子可临时切换为“测试叉面”。两者可单开、同时开或都关闭，共四种组合；开关不会删除或覆盖内存中的 DXF，关闭即恢复图纸。测试齿由打击圆齿尖、直线迎击面、牙长与有限三角背撑严格定义；“齿相位角”按用户提供的 [Beetleweights for Dummies](https://docs.google.com/document/d/1IxulfzmkxP2UOKo1TPsEDITqoBg-wLu-mH5bXBPuA1U/edit?usp=sharing) 中 rake angle 定义，是迎击面与齿尖半径之间的前角，不是第 0 齿的圆周位置。正前角表示齿尖沿实际逆时针转向相对齿根超前、较易抓入；输入始终表示最终装配后的物理正负，单轴镜像只改变朝向，构形会预补偿其对有向角的反转。测试叉严格是一条从局部铰点 O=(0,0) 到叉尖 T=(D,0) 的理想无厚度线段；质量由高级项显式输入，质心与绕质心惯量按均匀细杆计算。

## 已实现

- DXF 导入、单位识别、转轴点选、镜像、画布放大/缩小/适配、鼠标滚轮缩放。
- 武器 RPM、角速度、图纸刀尖速度、空载车速、瞬时每齿 bite、动能、扭矩和可用功率估算；转动惯量输入单位为 `kg·mm²`，内部以 `× 1e−6` 换算为 `kg·m²`。武器旋转组件质量以 `kg` 独立输入，与转动惯量分别控制接触/关节平动响应和绕轴转动响应。
- 武器电机条件预设：P2306 的 4S 用户降额与 6S 官方电输入点、X2212 V3、XRotor 2812、NIDICI 2807、XTO-3115；均可编辑。厂家桨测功率统一按电输入标注，不伪装成机械轴功率。
- 行驶参数：KV、功率、扭矩、传动比、效率、轮径与等效抓地。1.36 kg 默认已改为厂家明确用于 3 lb 机器人的双 Blitz Lite 1604 2850KV + 29.16:1，并使用其 14.8 V 整套减速电机测功数据。原双 1806 3000KV + 20:1 仍标为“用户候选，待型号/实测核验”；另增加了 Repeat Compact 1806 官方目录只读项，因缺扭矩不会套用。已填的行驶效率、经验负载速度折扣、抓地上限与正相电流限值始终参与求解，“高级参数（仅显示）”按钮只控制输入的展开/收起。当前“牵引需求超限比例”不是由轮速与地速求得的真实瞬态滑移率，传动系转动惯量尚未建模。
- 量级预设：150 g、220 g、454 g、1.36 kg、5 lbs、13.6 kg、110 kg，并同步动力与推荐靶子。只有内置 1.36 kg 图纸带有可审计的起始武器/叉子质量；其余预设会清空两项质量并进入“待补质量”，播放和单步保持禁用，直到用户填写实测/等效值。质量不会从上一预设继承，也不会按 `I/R²` 反推。
- 叉子：当前 DXF 实体或理想无厚度测试线叉都是有显式质量的独立刚体；其局部原点通过转动铰链连接到底盘，铰点 X/Y 只相对武器原点定位。装配初态解析求取一个绕固定铰点的转角，使真实最前叉尖恰好位于 Y=0 mm 且整个轮廓不穿地；不平移铰点，不把靶子搬到叉尖。开始求解后叉身继续受重力、铰链与地面接触共同约束。
- Rapier 2D 联立刚体：受限底盘、铰接叉子、转轴武器、靶子与无限地面处于同一刚体世界；转子命中会降速，底盘会承受水平反作用。显式武器质量与叉子质量都从整机质量扣除，剩余值才是底盘质量；求解器严格要求 `I ≤ mR²` 且底盘质量大于零，不再用 `I/R²` 伪造转子平动质量或夹取输入。当前底盘只有水平自由度，竖向与俯仰由理想地面约束；叉子保留绕铰点的独立转动自由度。
- 武器接触事件分为“牙齿命中”和“刀体 / 背板碰撞”两条独立计数。每个连续接触 episode 在第一次出现可测冲量时冻结归类，并以真实几何 source index、法向冲量和完整能量账显示；刀体 / 背板碰撞不会增加牙齿命中次数，也不会生成 bite。短暂流形断开会按物理齿距 / 一周转角去重，回滚、预计算缓存与进度条 seek 均保存两套计数。
- 武器和行驶都可选择“真实加速”或“设定初速”，并可用 `0–100%` 指令测试；行驶含牵引、功率/扭矩上限和滚动阻力。“设定初速”是在 `t=0` 直接给定已有速度/转速的边界条件，武器会立即带入 `½Iω²` 储能，并不代表所填电机能在当前进场距离内达到该转速；常规测试应使用默认“真实加速”。
- 播放 / 暂停 / 单步 / 重置、`0.01×–16×` 时间倍率和可拖动进度条。用户可选择预计算到 `0.0005–4 s` 中的任意固定步时刻；页面始终按固定 `0.5 ms` 物理步生成对应轨迹，完成后播放与 seek 只读取缓存帧。
- 碰撞面板持续显示靶子质心的场景 X/Y 坐标（mm），速度仍使用 m/s；`BiteSim.getState().target` 同时保留内部 SI `pos` 和明确使用毫米的 `positionMm`。时间轴、单步与完成提示显示到 `0.0001 s`，因此不会把半毫秒终点误写成整毫秒。
- 左侧所有设置区均可收起/展开；数字输入允许在编辑时临时删空，只有离开输入框或按 Enter 时才提交校验。靶子默认按 X×Y×Z 与密度自动回填质量，切换到“实测 / 等效质量”后才手动输入。

1.36 kg 起点的武器质量默认为 `0.148327787 kg`：内置 DXF 闭合外轮廓面积 `3940.679136 mm²` 减去十二个内部闭合环 `1578.771697 mm²`，得到净钢板面积 `2361.907439 mm²`，再乘当前 `8 mm` Z 宽与 `7850 kg/m³` 钢密度。这只是图纸钢板质量的可追溯起始估算，不包含轮毂、紧固件、带轮或轴。成功导入新武器或叉子 DXF 会立即清空对应部件质量并进入“待补质量”；失败导入则保持图纸、质量和仿真状态不变。更换图纸或使用实机时必须称重完整组件后填写，页面不会根据惯量暗中改写该值。

计算仍坚持同一 0.5 ms 固定步、80 µm 几何硬门和整步事务回滚。当前版本已缓存不变 CAD 元数据与叉子包围半径，并在保守扫掠包围域之外跳过精确轮廓求交；这些优化不修改接触解。预计算分块预算已从 8 ms 调整为 32 ms：锁定同一源码的完整 4 s A/B 中，8,001 帧、事件、最终状态、25,733 次 Rapier 子步和 3,338 次回滚逐项相同，内部构建墙钟由约 63.18 s 降至 30.68 s。当前版本优先加载本地官方 `@dimforge/rapier2d-simd-compat@0.20.0` CPU WebAssembly SIMD 后端；若浏览器不支持 WebAssembly SIMD 或该后端初始化失败，会自动加载同版本本地 `rapier2d-compat`，并在事件记录与 `BiteSim.getState().physics` 中披露实际后端和回退原因。两套引擎资产均随页面提供，不依赖运行时外链，直接 `file://` 打开也保留自动选择能力。默认 1 s、0.5 ms 固定步的同机 A/B 中，2,001 个完整帧、事件、穿透量、3,595 次 Rapier 子步和 55 次回滚逐值相同；五次真实墙钟中位数由 3,042.408 ms 降至 2,013.970 ms，约缩短 33.8%。这是 CPU SIMD 性能优化，不改变碰撞几何或物理结论，也不能用来替代物理回归。小规模四刚体并不适合把约束、关节和回滚另写成 WebGPU 求解器；后续界面流畅度升级可把完整物理核搬入 Dedicated Web Worker，但直接 `file://` 环境需要保留主线程回退。

“有效输出系数”是模型修正百分比，用于暂时容纳电池压降、ESC 限流、传动损失与安装差异；它不是无人机桨叶测试常见的“力效 `g/W`”。后者不能换算为旋转武器扭矩或冲击力。

如需由 KV 粗估理想 SI 扭矩常数，页面采用 `Kt = 60 / (2π·KV) ≈ 9.5493 / KV`（`KV` 为 rpm/V，结果为 N·m/A）；相电流定义、测量方式、绕组连接和厂家 KV 容差都会造成偏差，具体型号与台架实测优先。武器或行驶的相电流输入为 `0 A` 时表示“不知道可核验的相电流上限”，求解器不会暗造一个限流值；厂家桨测表的电池侧电流也不会直接填入该字段。参见 [ODrive 的 KV / Kt 说明](https://docs.odriverobotics.com/v/latest/articles/component-selection.html)。

## 材料与摩擦

武器材质提供 Hardox 500、Hardox 600、PEEK、PLA+、TC4；地板提供欧松板、钢板、铝板；靶子可选择低碳钢、铝合金、HDPE、胶合木或自定义。

页面显示并使用以下工程估算值：

- 刀—靶动摩擦系数 `μk`：限制切向冲量，`|Jt| ≤ μk · Jn`。
- 靶—地界面显示 `μs / μk`；当前 Rapier 刚体求解使用 `μk` 作为统一库仑摩擦，`μs` 仅为材料参考值，尚未建立独立的静摩擦粘着—起滑判据。
- 地板恢复系数：决定简化反弹。

默认表只针对干燥、清洁、常温的材料对。表面处理、涂层、油污、尖端几何、冲击速度与材料变形会使真实值显著变化；“摩擦修正系数”默认固定为 1，只有取得同表面状态的试验值时才应修改，不能用它拟合想要的击飞高度。摩擦不会被错误地当作 bite、切深、材料断裂或结构强度。

“高级参数（仅显示）”是纯界面折叠：开关不会重置正在进行的仿真，也不会为摩擦、恢复系数、接触冷却、刚体上限冲量或电机模型选择另一套公式。隐藏输入保留其数值并继续参与求解。

局部材料模式不会从视觉效果反推切削参数。以下两类数据仍可作为研究输入记录：

- 与当前刀具、靶材和速度条件相符的最小未切削厚度 `h_min`；
- 有材料状态与试验来源的断裂能 `Gc`。

对导入 CAD 与参数测试齿，“有限材料”模式不再静默借用 Rapier 完全刚体冲量。只要连续塑性/断裂、沟槽历史与完整剩余材料边界的“回滚 → 最早压缩 TOI → 联立接触 → 余步重演”尚未通过时间步收敛验证，首次承载武器接触就会回滚整个固定步、标记材料模型域停止，并保持靶子和转子的接触前状态；不会输出击飞量或“现实切削量”。这是对缺失物理的明确拒绝，不是按齿数或 bite 经验缩放冲量。只有用户显式选择“理想刚体上限对照”时，参数齿直线迎击面、有限背撑或导入 CAD 才按完全刚体接触传递冲量。

这两个输入不能由刃圆半径自动猜出：[Coelho、Diniz 与 Silva 的正交切削试验](https://www.sciencedirect.com/science/article/pii/S2351978917302275)表明 `h_min` 会随切削条件、最大未切削厚度及其增长历程变化。内置 HDPE 的 `Gc = 4 kJ/m²` 只引用 [Gent 与 Wang 的薄条、准静态、低摩擦切割/撕裂试验](https://onlinelibrary.wiley.com/doi/abs/10.1002/%28SICI%291099-0488%2819960930%2934%3A13%3C2231%3A%3AAID-POLB12%3E3.0.CO%3B2-6)，明确属于跨牌号、跨速率参考，不是当前高速撞击的精确常数。

## 物理边界

这是可审计的二维刚体 / 局部材料工程模型，不是有限元或完整材料失效仿真。

- 理想每齿进给 bite 是接触点相对 X 向进给除以实际齿通过频率；它不自动等同最终切深、裂纹尺寸或可传递冲量。增加齿数不能作为 `1/N` 冲量修正项；没有已验证的历史材料表面时，有限材料模式会在首次承载接触前回滚停止。
- 闭合 DXF 的真实凹外环减孔实体用于接触，不会用凸包填平牙谷，也不会把孔填实；每个物理子步还以同一组实体环执行独立穿透门。牙形归因只来自外环上识别出的迎击牙瓣，孔边界不会被误计为牙齿。材料模型仅处理武器 Z 重叠切片，其余 Z 宽仍作为结构支承。
- 非识别齿段的刀体 / 背板碰撞仍是会传递冲量和改变能量的真实刚体事件，因此单独计数并公开 source / 冲量 / 能量账；它不能被静默丢弃，也不能冒充牙齿 bite。
- 武器 RPM 与储能的上方卡片是无负载理论值；实时卡反映起转、命中降速和电机恢复。传动比定义固定为 `i = 电机转速 ÷ 武器转速`。
- 叉子与底盘之间使用位于叉子局部原点的理想转动铰链：平移关系由“叉子铰点 X/Y”确定，叉子世界角度由重力和接触求解。当前没有隐藏的铰链角度限位、弹簧或旋转阻尼；真实机构若有止挡、轴套摩擦或回位件，需要后续以实测参数建模。
- 底盘目前是仅沿 X 运动的一维刚体约束，没有轮组垂向、底盘俯仰、载荷转移或整机起跳自由度；这些结果不能用于判断整机飞行姿态。
- 材料模型不追踪温升、应变率完整本构、刀具磨损/崩刃、三维裂纹扩展和碎片多刚体；检测到需要这些自由度的工况会判模型域无效并停止。
- 电机厂家桨测功率/电流只是带条件参考，不能代替实际电机、ESC、电池、减速器和轮胎台架数据。

适合用于早期比例、速度、几何干涉、击飞趋势与方案比较；不能单独用于强度验证或安全结论。
